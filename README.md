# Customer Churn Analysis | SQL Server & Power BI

## 📌 Overview

This project analyzes customer churn data to understand customer behavior, identify churn patterns, and find the main reasons customers leave.

SQL Server was used for data preparation and analysis, while Power BI was used to create an interactive dashboard and visualize the findings.

## 🛠️ Tools Used

- SQL Server
- SQL
- Power BI
- DAX
- Power Query

## 🎯 Project Objectives

- Analyze customer churn patterns
- Identify common reasons for customer churn
- Understand churn across different customer segments
- Prepare and validate customer data using SQL
- Build an interactive Power BI dashboard
- Generate insights that can help improve customer retention

## 🔄 Project Workflow

1. Imported the customer dataset into SQL Server
2. Cleaned and prepared the data
3. Created SQL views for analysis
4. Connected the prepared data to Power BI
5. Created DAX measures and KPIs
6. Built an interactive dashboard
7. Analyzed churn categories and reasons

## 📊 Dashboard

The Power BI dashboard provides insights into:

- Total Customers
- New Joiners
- Total Churn
- Churn Rate
- Churn by Customer Demographics
- Churn by Services
- Churn Categories
- Churn Reasons
